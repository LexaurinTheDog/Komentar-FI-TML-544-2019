# Tavaramerkkilain (544/2019) kommentaari

Kommentaari suomalaiseen säädökseen: **Tavaramerkkilaki 26.4.2019/544**. Kommentaari kattaa **107 pykälää** (1–11 luku, mukaan lukien yhteisö- ja tarkastusmerkkejä, kansainvälisiä rekisteröintejä ja EU-tavaramerkkiä koskevat säännökset sekä voimaantulo- ja siirtymäsäännökset) **4 kommentaarin luvussa**; kunkin pykälän kohdalla esitetään säännöksen sanamuoto sellaisenaan ja sen jälkeen kommentaari.

Tekstin tila: Finlexin ajantasainen lainsäädäntö, lähteen metatietojen mukaan ajantasaistettu **26.4.2019** (alkuperäinen sanamuoto; lähdeteksti ei sisällä muutossäädösmerkintöjä). Lain mahdolliset myöhemmät muutokset on tarkistettava ajantasaisesta lainsäädännöstä.

## Menetelmä

Kommentaari on laadittu **yksinomaan paikallisten aineistojen perusteella** (Finlexin avoimen datan ajantasainen säädösteksti ja sen metatiedot), ilman kaupallisia oikeudellisia tietokantoja.
